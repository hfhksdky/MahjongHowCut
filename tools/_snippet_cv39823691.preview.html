Q11

书中解答：4s 1向听【7m x 43, 4s x 43, 7p x 40】

浮牌7m, 4s, 7p的比较。留下7p是因为有三面听的可能性。留下7m还是4s就看最终型的形状，靠近端牌的浮牌会更加优秀。要是成了双碰听牌，1s还是成了4s的筋牌这点也不错。

浮牌价值：7p > 7m > 4s

※一般来说，很难用上的牌大多数情况都是【容易打出的牌→容易胡到的牌】，所以多数上留下容易胡到的听牌是优秀的听牌



书中解答:5s 1向听【5s x 43., 7m x 42, 7p x 39】

有很多人不会直线切5s把。即便留下5s摸到附近的组成的两面听牌也是靠近中间的36s或者47s，因此需要理解到5s作为浮牌并不是那么强。

浮牌价值：7p > 7m > 5s

Q13

书中解答：9s 1向听【7m x44, 6s x 43, 9s x 43, 7p x41】

222m+345p + 11s + 678s就已经保证了3组面子跟1雀头的形状了，要的是两面搭子。6789s虽然是四连形，但要是摸了8s成了67889s就变弱了，组成两面搭子反而不利。推荐打9s固定678s。

浮牌价值：7p > 7m > 6s(9s)

※ 像以下的数牌组成的形状叫做四连形，虽说都是四连形，但数字的不同在价值上也会形成很大的差异

4567s (摸38s形成三面，摸56s形成两面)

5678s (摸4s形成三面，摸679s形成两面)

6789s (没法做成三面听牌，摸57s形成两面)
