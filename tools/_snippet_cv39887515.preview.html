Q15 

书中解析：89m 2向听【4m x 24, 8m x 20, 9m x 20, 2s x 20, 4s x 20, 7s x 20】

胡牌形状应该是【四面子1雀头】的5 block，现在手中有6 block，我们称它为“面子超载”（或者搭子超载）。选择搭子的时候遵循这【两面 > 坎张 > 边张】这个强度顺序，这里就应该拆掉一组最弱的搭子，也就是89m。至于先切8m还是9m，要是断么重视的话就打9m，要是重视危险度的话打8m。

搭子的强度排序

两面 > 坎张 > 边张

34p > 24s > 89m

Q18

Q19

书中解析：4m 2向听【4m x 20, 8p x 20, 7s x 20, 2p x 18, 4p x 18, 2s x 18】

6 block搭子超载，按理来说应该要拆掉一组最弱的...但【选不出弱搭子】【能看到三色】【3雀头很弱】这些理由，那就推荐维持6 block打4m把


※【3雀头很弱】在这里维持6 block的其中一个理由，但对新手来说很容易搞混乱。要是想深入了解的话可以查看【uzaku麻将学习 牌效率】中的【3雀头最弱理论】（译者注：感谢zefurikuzefuriku提供的翻译https://www.bilibili.com/opus/616316429610661435）

Q21

书中解析：6s  2向听【4m x 39, 4p x 39, 5p x 39, 5m x 30, 8p x 30, 6s x 30】

把索子部分看成2 block的话就有6 block了因此超载了。6677s切掉1枚6s弄成3枚牌组成的搭子是个比较柔软的做法。后面，要是摸上了3p，手牌就可以变成了以下的完全一向听。

※ 6677s这种形状称为【double面子】，这里切掉67s的打法叫做【拆掉double 面子】。比较6s跟7s的危险度的话，基本上靠中间的危险度越高，因此先切6s。
