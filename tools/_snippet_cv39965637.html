Q37

书中解析：8m 1向听【8m x 19, 5s x 15, 6s x 15, 6m x 11】

打8m进入完全一向听。

为了固定dora的6s对子而打掉5s的话，摸到47p的时候会形成要不双碰要不坎张的听牌（都是4枚）。

打8m的话，摸到47p的时候，虽说要打dora立直，但多了个平胡，听牌枚数翻倍（8枚），综合力上来讲更有利。


Q41

书中解析：6p 1向听【6m x 12, 3p x 12, 6p x 12, 8m x 10, 8p x 10】

带有6m, 6p, 6s三组雀头后补的一向听。雀头只需要1个就好，那就从6m还是6p拆掉一个。

这里推荐打6p。这样组的手牌，进张最多，摸到25p4p也能做成两面听牌。特别是摸到2p就更有魅力了

打6m的话，当饼子上有变化的时候，愚形听牌变的很浓厚
