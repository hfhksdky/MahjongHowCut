Q57    

书中解析：8p 1向听【4p x 19, 8p x 19, 2p x 15, 6p x 15, 3s x 8, 7s x 8】

打4p或者8p都是进张最大，门清的话打4p或者8p都有，但考虑到鸣牌可能的话打8p是有压倒性的优势。如果打4p要了两坎的话会变成以下的进张，就不能进行dora碰听了。


Q58

书中解析：4p 1向听【2p x 19, 4p x 19, 8p x 15, 3s x 10, 4s x 10, 7s x 10】

打2p或者4p都是进张最大。因为dora是2p,切4p期待值最大。自摸3p虽然要打掉dora,但是断么平胡dora1的原因，打点十足。【绝对要用上2枚dora】这个理由而切掉8p的话就会损4枚（比最大进张）。比起摸3p要打dora，进张数少4枚才是最差的选择。

Q59

切3s还是6s虽然没有很大的区别，要是成了以下的形状的话变成断么平和三色的可能性也不是不可能，所以冷静的先切3s把
