Q65    

书中解析：9m 2向听【9m x 28, 4p x 28, 8p x 28, 3m x 22, 6p x 22, 4s x 22】

6 block的3雀头形状。44688p的形状容易形成1雀头加1面子，也就是说其他的雀头后补留下的话意义不大。

打9m, 4p, 8p都是瞬间拥有最大的进张数，但打9m的话会形成以下的牌型会有更广的一向听的可能。


Q66 

书中解析：4p 1向听【4p x 16, 8p x 16, 9m x 12, 6p x 12, 2m x 8, 3m x 8】

9m这个对子肯定是变不到两面的，那么就让牌型变得容易平胡把。打4p变成468p的两坎形状是最容易出现平胡的形状。

Q67

书中解析：4p 2向听【2p x 28, 4p x 28, 8p x 28, 3m x 24, 6p x 24, 9m x 20】

不要2个雀头候补的例外形。要是留着2个雀头继续的话，很容易会【无役无dora听牌】。雀头候补的9m的没法期待出变化，这里就往最容易形成平胡去做牌更好。

把牌拆分成以上的block的话，就很容易明白饼子部分只要1个block就好。进张数上打2p 4p 8p都是一样的，但容易形成平胡的话，还是打掉可能会变成暗刻的4p。

Q68

书中解析:4s 2向听【2p x 28, 8p x 28m 4s x 28, 4p x 24,6p x 24, 9m x 16】

打4s 2p 8p都是一样的进张数。为了容易形成平胡饼子部分就这么留下把。
