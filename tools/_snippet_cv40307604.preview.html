Q79

书中解析：2m 1向听【2m x 8, 4m  x 8, 3p x 8, 7p x 8, 2s x 8, 4s x 8】

按照上面那样拆分的话，就是6组搭子的搭子超载

因为dora是对子所以基本上要食断。碰上dora后就是满贯确，没啥不满的，但也留下其他的满贯听牌的可能性。

要是副露前提的话，那就为了断么确把所有的索子留下就比较好做。即便摸到不能听牌的牌但也有不错的自摸牌。

自摸5s的话当然就是两面变化，自摸467s的话会让手牌更有厚度。当然也有了吃红5s的准备。

Q80

书中解析：2s 1向听【2m x 8, 4m x 8, 3p x 8 , 7p x 8, 2s x 8, 4s x 8】

6 block，搭子超载，那就把最弱的搭子拆掉。3p对子是dora所以不能拆，7p对子的话有两种的两面变化，所以留下这么优秀的搭子。

留下的24m跟24s，同样都是坎张搭子比较，自摸5m的时候是3面听，因此24m搭子比较强。所以切掉最弱的24s搭子，因为有红5s的所以有2s开始。摸到6s的话就往断么发展。
