Q81

书中解析：1p 2向听【6p x 35, 6s x 31, 1p x 32, 7p x 22, 9p x 22, 1z x 22】

6 block，搭子超载，那就把最弱的1p对子搭子拆掉变成5 block是推荐的打法。

要是按着6 block去切7p的话，就会错过摸8p后变成下述的强形。


Q82

书中解析：2p 2向听【6m x 15, 1p x 15, 2p x 15, 6p x 15, 0s x 15, 6s x 15】

因为6 block，所以推荐把最弱的12p边张搭子拆掉变成5 block。

按照6 block继续的打法打7p的话，摸到8p的时候不仅形状微妙，而且也损失掉了七对子的可能性
