书中解析：3s 1 向听【3s x 19, 1s x 18, 5s x 18, 2m x 8, 3m x 8, 6m x 8】

打3s就是进张最大，也是容易做成平和的一手。

要是先进了万子变成索子听牌的话，3s -> 5s这个切牌顺序听坎2s也不算很坏

打1s或者5s保留两组雀头的打法虽然说比较灵活，但是何有可能在没变化下完成万子部分导致愚形的索子待牌的听牌。没错，大多数情况下，【慢慢等变化是来不及的】。特别打5s的话就无法对应摸到6s的情况。
