Q85

书中解析：7m 1向听【7m x 16, 1s x 12, 5s x 12】

进入一向听的话就是打7m, 1s, 5s这3种。这个形状的话，那就直线打7m，要最大进张并且两面两坎的1向听。要是坎张进张后就是平和，要是两面部分先完成就成了无役的坎张听牌，没想到是个天堂还是地狱的形状，要是能接受这个形状就打7m拿最大的期待值。

另外，即便没有变化，成为平胡的概率是二分之一。

（※实际上摸6s也有变化）

Q86

书中解析：5s 2向听【5s x 32, 7m x 28, 8m x 28, 3s x 28, 7p x 24, 1s x 24】

这是一个确保有5 block的强形。按照留两组雀头的打法打5s就是进张最大，期待值最大。打8m的话就会相对损4枚。自亲的dora1【立直也有3900起】确，因此没理由放弃那4张有效牌。

Q87 (译者注：打错题目的我T.T，解析中修改过了）

书中解析：5s 1向听【7m x 12, 5s x 12】

要是因为79p是愚形而打掉，就会退回两向听了。实际上打7m或者5s以外的牌就不会是1向听的牌的形状了。打5s后摸8p后就会直线听牌这点不会逃掉，加上摸79p的话纵向发展的话就是完全1向听了。


Q88（还有这道T.T，解析中修改过了）

书中解析：1p 2向听【5s x 28, 1p x 24, 7m x 20, 8m x 20, 2p x 16】

虽然说搭子齐了，但是有愚形的2向听。要是把79p的愚形拆了就会退回3向听。现在还是2向听，因此枚数差就不是那么重要了，应该保留强形来推进手牌。这里就推荐固定dora对子打1p。

Q89

书中解析：7p 1向听【5s x 24, 7p x 17, 9p x 17, 7m x 13, 8m x 13, 3s x 12】

想要的是雀头，所以雀头的第一候补就是索子。留下3455s的话，那就自然地会切掉79p了。7p跟9p，要是重视安全度的话推荐先从内侧的7p开始。


也有为了断么或者0p而先打9p，但7p摸成对子后，也会在完全断么前立直，再且摸进4p或者0p最后也是要打7p，因此切9p后留下7p的价值不大。

Q90

书中解析：7p 1向听【5s x 24, 5p x 17, 7p x 17, 7m x 13, 8m x 13, 3s x 12】

要的是雀头，因此想把所有的索子留下。考虑到5p的纵向发展就打7p就是期待值最大。

虽说后面可能会打出0p去听牌，但打点上已经足够了，就没必要执着于打0p这种东西了。
