Q97

书中解析：4p 1向听【7m x 41, 4p x 37, 1s x 36, 4s x 36, 8m x 17】

打4p，听牌率，胡牌率，期待值，全部最大。

这788m的形状，既能做出两面也能做出雀头的便利形状。

留下1234这个4连形的形状，能通过更多的摸牌形成两面听牌。

记住【因为有4连形跟其他搭子所以留下788m】就好。

Q98

书中解析：1s 1向听【7m x 39, 0p x 37, 1s x 34, 4s x 34, 8m x 17】

双dora 0p的浮牌。那就围绕着这个0p横向或者纵向发展来做牌吧。然后留下788m这个形状也不错。摸上4p或者6p横向发展的话就用8m做雀头，摸5p的话就纵向发展成为雀头然后形成69m的两面听牌。

记住【因为有绝对不能打的浮牌（比如赤宝）跟其他搭子所以留下788m】就好。

Q101

书中解析：7m 1向听【7m x 37, 3s x 36, 4p x 33, 8m x 13】

2334s的中膨形，虽然是容易形成两面搭子，但很难做成雀头的形状。这个中膨形要做雀头的话也只有中间的2枚3s。那么不期待用中膨形来做雀头的话，就固定8m雀头，去找4p靠张就比较有利。

记住【有中膨形的话那跟雀头固定搭配不错】就好。
