Q103

书中解析：8m 1向听【7m x 38, 3m x 37, 3s x 29, 8m x 25】

2223m的形状，容易做出1组两面跟雀头的形状，最终形是14m3m的3面听的强形。那就配合这个强形来找其他的搭子把。雀头上能保证从2223m出来，其他的（对子）搭子用途价值比较低。那这样的话，就打8m去固定78m的两面就比较好。这样做下去的话，最终形肯定是个两面以上的听牌。

打3m, 7m, 3s就单纯进张数最多，但愚形听牌率也高平胡也难。因此，胡率跟打点来说综合能力是个劣势。

Q105

书中解析：7m 1向听【7m x 58, 3p x 45, 6p x 45, 3s x 45, 6s x 45, 8m x 20】

拿到这手牌后，发现断么是最容易达成的就是个关键点。

那就拒绝摸9m会破坏断么的7m就是期待值最大。

4连形有4种的两面听牌强形。虽说有可能会有双碰听牌，但这次的双碰听牌也至少确保了断么听牌。

4连形有很多的进张，既能转换成变强的3面听的同时，也有可能转换到变弱的坎张听牌或者双碰听牌。愚形听牌的话，就要一边思考怎么应对（比如是否摸切），一边推进手牌。
