Q109

书中解析：4p 1向听【1s x 36, 7m x 33, 4p x 29, 8m x 17】

打4p，相对于跟打1s相比少了7枚，但多了全带或者一杯口这个打点的有利形状。这手除了门清，也可以吃9m或者1s形成高目全带的听牌。

这次用来副露的形状，1123s这样的复合型价值就较高。另一方面，留下4p摸到2p 6p的话就是愚形听牌，因此实际上枚数差就没那么重要了。

Q111

书中解析：1s 1向听【1s x 36, 7m x 33, 6p x 29, 9p x 29, 8m x20】

虽说能看到全带，但这手高兴的是摸到dora的9p能听牌。打点方面虽然全带那边高，但相比之下，dora自摸能确定1翻，而全带无论摸到什么，除非改变听牌，否则役种不一定成立。

在这，【进张最大】还有【摸到dora立直听两面】这些理由打1s就是期待值最高。

Q112 自己打过4p

书中解析：8m 1向听【1s x 35, 7m x 32, 6p x 29, 9p x 29, 8m x 20】

因为自己打过4p，因此6p的靠张的价值就下降了。

（※成了以下的形状不仅会振听，而且单纯枚数上也有改变）

那这样的话，就瞄准全带把。比起单纯看进章枚数，有价值的进张枚数才是最重要的。
