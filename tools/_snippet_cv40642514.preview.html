Q117    

书中解析：8s 立直 听牌【8s x 4】

听坎8p。要是默听，饼子部分也只有自摸36p5p的3种听两面的变化。虽说有自摸47p去听双碰的变化，但现在是无役状态不能荣和这点很痛。

自亲8巡了不太有时间去等变化了，推荐就听牌就立了。

Q118

书中解析：9p 1向听【4s x 4, 7s x 4】

虽说自亲，【无役】【无宝牌】【愚形听牌】，可以说是集齐了所有不利因素。

因为有4567p跟4567s的2个连形，为了消除愚形听牌（坎8p）拒听拆牌也是来得及的。要是有了中或者赤的1翻提升，又或者有了好形变化那时候立直就很不错。

Q119

书中解析：9p 1向听【9p x 15, 4s x 15, 9s x 15, 5p x 12】

打9p, 4s, 9s进张数都是一样的。

饼子部分455679p的形状，是36p8p的两面坎张。索子部的467899s这边，有个隐藏的坎5s进张。

饼子成型的话就是9s中的双碰听牌，索子成型的话即使36p的两面听牌。

虽然说听到带dora中的双碰很有魅力，但最终形上还是想要听牌枚数多的两面听牌。那就为了容易形成两面听牌就推荐打9p。

Q120

书中解析：9p 1向听【9p x 15, 4s x 15, 8s x 15, 5p x 12】

打9p, 4s ,8s都是一样的进张枚数。

饼子部分455679p的形状，是36p8p的两面坎张。索子部分则是468s的两坎。

为了提高最终形是两面听牌的这个可能性，愚形部分（468）就不要拆掉打9p就是期待值最大的。

Q121 东1局 东家 6巡 宝牌中， 上家打出中，碰么？

书中解析：碰打9p 1向听【9p x 19, 5p x 16, 5s x 15, 7s x 15, 9s x 15】

dora中碰。虽然455679p两面坎张，55799s的进张是5689s更广的形状。要听牌最优先的话，那就是要找目前最大进张的，所以打9p是正解。

因为对手会警惕碰宝牌，你选择用来“钓鱼”而留下坎8p的听牌，就有点做过头了。

首先听牌肯定是最优先的，就打掉让手牌进张数最大的牌把。

Q122  东1局 东家 6巡 宝牌中 ， 上家打出中， 碰么？

书中解析：碰打2p 1向听【2p x 16, 9p x 16, 5s x 12, 7s x 12 ,9s x 12】

dora 中碰。碰之后打2p还是打9p都是进张数最大。

55799s是接受5689s的最广的形状的，打掉的话会比其他少4枚进张枚数。

最终形上比起听坎3p，靠近端的坎8p更好，因此打2p是正解。
