Q144 all last，胡牌就1位的条件

Q145 all last  胡牌就1位的条件

书中解析：7p 1向听【7p x 22, 2s x 22, 0s x 18, 1s x 17, 3p x 13, 6p x 13】

虽然说【全都要鸣牌】而去断么确定打掉1s的形状，但会损掉了36s的进张。其实打1s也只是增加了碰7p这要素。但是碰了7p会破坏掉【这手最强的3面听】而变成双碰听牌，价值降低。反之固定好【这手最强3面听】打7p构成最强的1向听把。

Q146 all last 胡牌就1位的条件

书中解析：7p 1向听【7p x 23, 2s x 23, 6p x 17, 3s x 14, 6s x 14】

虽然说打2s是固定索子3面听，但碰听（7m碰还是7p碰）的时候，1s就成了不能胡牌的3面听了。

比起3面听，为了碰听确定断么，打7p就是基本。
