Q155

书中解析：1p 2向听【4m x 28, 3p x 28, 8p x 28, 1p x 26, 6p x 26, 3m x 22】

瞄准的是断么三色。虽说三个雀头后补，但目前现在2向听所以没必要强行弄成2个雀头后补。要是摸了7p发展成下面这样的手牌的时候，留下的4m就会进张更广，三色也容易做出。

选择打4m的人，不妨考虑下下一巡摸到2p后的形状。不仅留下多余的浮牌，也会破坏掉了断么三色


Q156

书中解析：1p 2向听【8m x 27, 1p x 27, 6p x 27, 4m x 24, 3p x 23, 8p x 23】

678三色的2向听。万子部分有25m7m的两面坎张进张所以不动。带着2组雀头后补跟有三色的意识打1p是正解。

Q157 


书中解析：4m 2向听【4m x 28, 1p x 28, 8p x 28, 3p x 26, 6p x 26, 3m x 22】

本命是678三色，但有个不能断么的雀头后补（1p对子）有点不满，那先固定两面好了。

要是先摸进7p的话就直线瞄准三色，先摸到4p或者5p的话就转换方向瞄准断么就不错。

Q158

书中解析：1p 2向听【4m x 24, 8m x 24, 1p x 24, 6p x 24, 3p x 20, 8p x 20】

要是有1向听的时候有2组的雀头后补的意思的话打1p是正解。

虽说678三色是本命，但要是一上来打8p的话，468m的两坎摸进靠张的话，会使手牌多了无用的浮牌。
