Q161

书中解析：6m 1向听【3p x 59, 3m 46, 6m x 46, 2s x 45, 8s x 45, 4p x 23】

这个牌型是【打姬小笨蛋】里出来的。

单纯进张最广就是打3p，但除了饼子形成雀头的话就会变成双碰听牌。这里就打6m瞄准三色一气两天平把。无论切哪张牌，进张都很广，几乎可以保证听牌。因此比起单纯追求进张数量，更应该重视好形的听牌率。

Q162 

书中解析：6m 1向听【3p x 53, 2s x 45, 5s x 45, 3m x40, 6m x 40, 4p x 20】

没dora的手牌。因为摸到了会破坏断么的牌，使得一气的价值上升了。单纯打3p就是进张最广，要是有第二个雀头后补的话就会形成双碰听牌。也有为了三色去打4p这一手，但这样的话就没一气了。这里打6m，自然的瞄准了345三色以及一气然后选择期待值最高的牌去做把。
