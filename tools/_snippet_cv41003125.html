Q163

书中解析：9s 1向听【9s x 20, 7p x 16, 8p x 16, 8s x 12】

打8p的话就提前覆盖到了边7p的平胡一气最好形，但大多数可能最后听到边7p去。想摸到能形成最好形的7s也只有4枚，单纯计算的话是25%（4/16）。剩下的75%就是【没有平胡的愚形一气】或者【无役】的听牌。

那就放弃一气打9s进入完全一向听，那么听牌的时候多数就是平胡。因为没了一气，因此摸到7s也能跟1s去交换多了个断么，因此看起来是个里目但也不是。

Q164

书中解析：8p 1向听【9s x 20, 8p x 19, 7p x 16, 8s x 15, 0s x 11】

进入完全一向听的话就是8p与9s的选择。

靠着端牌的69p的待牌就比较有魅力，推荐打8p进入包括一气的完全一向听把。

Q165

书中解析：9p 2向听【5p x 23, 9p x 23, 6s 23, 9s x 23, 5s x 22, 2s x 21】

6组搭子超载，拆掉最弱一撘。

没有愚形搭子的3雀头的形状，那就拆到一组对子变成2雀头把。考虑【摸到0p】跟【不要让打掉的牌变弱】，那就推荐拆掉靠近端牌额9p对子。

注意到这牌有一气的可能，别把6s切了。因为摸到7s的话，可以从狙击一气转到断么的情况也有。
