Q181 

书中解析：3p 1向听【3p x 19, 9s x 15, 8s x 13, 5s x 12, 6s x 9, 1p x 8】

想要的是雀头。留着3p即便后续靠上了2p或者4p也会导致面子超载而不知道要切啥。那么自亲6巡目的情况下，就冲着要最大进张，先制立直为目标把。

打3p的话索子部分4s ~ 9s都是有效牌。根据摸到的牌，听牌形状跟打点虽然说有所不同，但有了dora或者平胡这个役，要确保不用立直也至少有1翻在手。亲家先制立直听宝牌单骑或者边7s好像也不坏。

Q182

书中解析：8s 1向听【1p x 23, 8s x 17, 9s x 16, 2s x 13, 3s x 13, 3p x 12】

切1p就是进张最广，但除了摸到了dora 9s听牌以外,其他的进张都不太亮眼。那不如试着留下能带来亮眼的进张的部分来做牌呢？

打8s的话枚数上稍稍劣势，但至少也保证了平和。留下1p的话，也留下了清一色的可能性。

Q183

书中解析：9m 1向听【6m x 19, 9m x 19, 5p x 19, 5m x 15, 6p x 15, 9p x 15】

进入完全一向听是最好的，所以打9m还是5m的二择。

一瞬间，打5p固定dora 6p的对子看起来不错，但实际上不用强行固定对子也是可能用上这2枚6p。饼子的部分不是566p + 789p的形状，而是56p + 6789p这个形状。

这里打9m进入以下的完全一向听才是正解。

这么组的话摸到了25s，就是断平dora2的满贯听牌（听47p）。当然，也能对应摸上第3枚dora 6p的情况，那时候就是dora 3满贯了。

Q184

书中解析：5p 1向听【5p x 20, 5m x 19, 4m x 16, 6p x 15, 9p x 15】

打5p或者5m都是完全一向听。

实际上打5p就是发展去等36m的听牌，打5m的就是发展成等47p的听牌，考虑到避开跟dora相同花色的情况，从枚数上看还是打5p有利。

实战上也要看看是不是有断么的变化，灵活的打5m也是有可能的。
